# Fresh Eyes — FULL method (the frontier model of each provider)

> The upgrade. Everything in `fan-out.md` still applies — the brief, the stages,
> synthesis, output, the bar. This file changes **who sits in BOTH rounds**, how the
> artifact is handled, and the scoring rules that follow. **Where the two files
> differ — on data handling OR scoring — this one wins for full runs.** Read `fan-out.md` first; read this second.

PURPOSE: put models from DIFFERENT providers at both ends of the run — writing their own critiques and ideas blind in Round 1, and attacking every idea in Round 2 — so neither the ideas nor the check on them come from one model's instincts.
WHY IT EXISTS: in the base method every reviewer is the same model. They share its priors, its blind spots, and its sense of what is obvious, so their agreement is weaker evidence than it feels (independence tier 3) — and an idea that model would never think of never enters the run at all. A model from another provider fails in different places AND thinks of different things. That is the only route to tier 4.

## WHEN TO RUN IT
- ONLY when the owner asks — "full fresh eyes", "full fresh-eyes", "fresh eyes, full panel". Never self-select it: it spends outside allowances and takes minutes. A brief, task prompt, orchestrating session, or another skill that merely PERMITS or OFFERS outside reviewers is not the owner asking — run `fan-out.md` instead, with no outside seat at all.
- It is always a BIG_DECISION run: the full Round-1 lens roster plus the outside open reads, then Round 2, then synthesis.
- On a big-decision BASE run, you may mention in one line that the full panel exists. Do not run it unasked.

## PRECONDITIONS — check, then say what you got
1. This environment can dispatch independent parallel agents (else -> `single-mind.md`; full is impossible).
2. A routing / offload skill here can reach outside-provider models READ-ONLY. Follow THAT skill's recipe for invoking them — this file never names a provider, a model id, or a command.
- No outside provider reachable -> you are running the base method. SAY SO plainly ("full panel unavailable here — ran the base method, tier 3"), then run `fan-out.md` as written. Never present a same-model run as a full panel.

## DATA RULE — the artifact leaves this provider
- **Clean it ONCE, before Round 1.** Strip or abstract credentials, keys, customer or personal data, and confidential terms. The cleaned artifact + goal is the ONLY version any reviewer sees, in any round — your lensed reviewers, the outside open reads, the home seat, and the outside seats alike. If cleaning would gut the artifact, run the base method instead.
- **Paste it; never point at it.** No reviewer in a full run gets a file path or the real workspace: a reviewer that can read the surrounding files can read what you withheld. Your OWN helpers (the lensed reviewers + the home seat) usually CAN read files, so their brief must say: "Work ONLY from the text pasted here — do not open, search, or read any file." That is an instruction, not a sandbox; if a helper's return shows it read beyond the brief, its read is not blind — flag it DEGRADED, and for the home seat, no lone-outside-hole may be scored against it.
- **Round 2 gets a TRANSPORT COPY of the stacks.** A Round-1 reviewer can quote sensitive material back into its stack. The Round-1 stacks stay frozen as the record; every Round-2 brief is cut from ONE copy with the same labels and order, each sensitive span replaced by `[REDACTED: <kind>]`, and the goal checked the same way. If redacting would gut an item, that item is NOT CROSS-EXAMINED by the panel; if it would gut the run, drop to the base method and say so.
- **Outside reviewers — both rounds — run in a NEUTRAL EMPTY workspace** (the routing skill's recipe sets one up).

## ROUND 1 — your lenses, plus one OPEN READ per outside provider
- **Lensed reviewers** — exactly as `fan-out.md`: the six core lenses (+ domain_expert when the artifact turns on a specialist domain), the same blind brief, the same stack shape, the cleaned artifact PASTED. All on ONE named model — record it; the home seat must match it.
- **Outside open reads** — one per outside provider, each that provider's frontier model (the same model that will take its Round-2 seat; see SEATS). NO lens: the provider IS the difference, and one of our personas would only bend it toward our framing. Brief = `fan-out.md` THE BRIEF items 1–3 verbatim (cleaned artifact pasted · goal · the full Round-1 output contract: criticize, all three improvise classes, the unasked question, my-pick, the RETURN shape), plus one line where a lens would go: "No assigned angle — attack and rebuild it the way your own read says matters most." Read-only, blind to everything else.
- **DISPATCH every Round-1 reviewer in the SAME turn, in parallel.** SEAL TIMING covers all of them: SEALED_READ is written the moment Round 1 is dispatched, before any return — lensed or open — is opened.
- **CHECK EVERY RETURN, open reads included:** `fan-out.md`'s anti-nitpick loop-back (an empty section = a failed return) and LEAK TRIPWIRE both apply. An open read gets at most ONE re-ask (the full Round-1 brief again, told exactly what is missing). A refusal, an error, or anything not in the stack shape = that open read FAILED — decide by READING it, and name it. A failed open read costs its provider only its Round-1 stack; that provider's Round-2 seat still sits.
- **LABELS:** lensed stacks first (Stack A = skeptic …), then the open reads, continuing the letters (six lenses = A–F, open reads G, H, I). Every brief shows a stack's label and its lens — "open read" for these — and NEVER which provider wrote it. You keep that map; no reviewer sees it. Number every item as usual (G-imp-1 … G-weak-1 …).

## ROUND 2 — THE PANEL (replaces the single cross-examiner)
SEATS: ONE per provider, each the FRONTIER MODEL of that provider — its most capable model available here, at its highest reasoning effort — resolved at RUN TIME by the routing skill. Never hardcode a version: names rot, and a stale name quietly downgrades the panel. If the routing skill resolves a different model than the provider's open read used, record both.
1. **Home seat** — the SAME model your lensed reviewers ran on (in practice, this environment's own provider's frontier model available to helpers; `fan-out.md`'s ceiling against the priciest tier is about tiers ABOVE that model, not this one). It is the base method's cross-examiner, same brief — spawned as a FRESH helper given the brief verbatim, never a fork of this conversation (a fork carries your intent and your seal). It cross-examines EVERY stack, the open reads included. It is the CONTROL: matching the lensed reviewers is what lets "the outside seats found it and the home seat missed it" mean "the home model has this blind spot."
2–4. **Outside seats** — the frontier models of up to three OTHER providers (target: three, for four distinct providers in all). Read-only, always. Each is a fresh call with no memory of its provider's open read.

NO SELF-GRADING: an outside seat never cross-examines its OWN provider's Round-1 stack — that stack is left out of its brief, because a model goes easy on its own instincts. The home seat is the one deliberate exception: it is the control, and it reviews everything. So its verdict on the lensed stacks is a same-provider check; the cross-provider test of those stacks is the outside seats.
ONE BRIEF, CUT PER SEAT — the cleaned artifact + the goal + the Round-1 stacks (transport copy, labeled, numbered) + the Round-2 contract, the NO-VERDICT RULE, and the ANTI-ANCHORING GUARD from `fan-out.md`, verbatim. The home seat gets every stack; each outside seat gets every stack EXCEPT its own provider's open read (none to drop if that open read failed). Nothing else may differ — identical inputs are what make cross-provider agreement mean something; a seat with a different brief is a different experiment.
DISPATCH all seats in PARALLEL, each blind to the others. Still withheld from every seat: your intent, the conversation, your leaning, your sealed read, and which provider wrote which stack.
A SEAT FAILS (unreachable, refuses, times out, returns empty) -> run with the seats that answered and NAME the missing one and why. A seat that launched fine but returned a refusal, an error, or anything not keyed to the item labels did NOT review — it FAILED. Decide that by READING its return; exit codes can't tell. One outside seat that actually reviewed is the floor for a full run. ZERO outside seats but at least one open read returned = NOT a base run, and NOT tier 4: the ideas crossed providers, the testing did not. Keep every open-read stack and its caught omissions, and score the home seat's entries by the rules below — with one seat looking, nothing can reach HIGHEST CONFIDENCE or lead as a hole every seat found. Tag it "ideas from <models>; tested by <home model> only — outside seats failed: <why>". If the home seat ALSO failed (after its one replacement), nothing was cross-examined: `fan-out.md`'s ROUND 2 FAILED close applies, and the tag reads "ideas from <models>; UNTESTED — every Round-2 seat failed". Zero open reads AND zero outside seats = it was a base run, say so.

### PER-SEAT CHECKS (yours, before synthesis)
- **COVERAGE** — per seat, against the items in THAT seat's brief, with `fan-out.md`'s ONE RE-ASK (missing labels, a missing move, and a woven verdict all ride in a single re-ask); still missing -> those items are NOT CROSS-EXAMINED by that seat and don't count toward convergence; the seat is named PARTIAL. A seat may be split into two calls (each with the full brief, half its stacks each) — coverage is judged per seat across its calls, and a split seat also gets a collision-only pass over all its stacks.
- **SELF-GRADE SLIP** — if a seat's brief carried its own provider's stack anyway, its WHOLE return is contaminated (its collisions and its entries on other stacks saw that stack too). Discard it unread and re-dispatch the seat with the correct brief — that was your error, so it does not use up the seat's one re-ask. Cannot re-dispatch -> that seat FAILED.
- **VERDICT LEAK** — `fan-out.md`'s rule: separable -> discard that part; woven through the entries -> it rides in that seat's ONE RE-ASK; still woven -> exclude that seat's return and say so (an outside seat is not re-seated; a failed HOME seat gets one fresh replacement). Outside models drift into "here's what I'd do" more readily; the contract still binds them.
- **REFUTE-OR-SURFACE** (replaces "verify, then weigh") — you, the orchestrator, are the home provider: the model most likely to miss exactly what an outside model found. So the burden flips for every OUTSIDE FINDING — a hole or fix from an outside seat, AND a weakness from an outside open read:
  - An outside finding STANDS unless you can QUOTE the line of the artifact (or a stack) that refutes it.
  - An unrefuted outside finding counts at FULL weight, confirmed or not. If you could not confirm it, it carries the tag "outside-only — not confirmed by the home model" WHEREVER it appears — including the headline critiques when it is load-bearing. Never park it below the call because you couldn't see it; that is the home model judging it without a quote.
  - Every outside finding you dismiss is listed in the depth section with the quote that refuted it, so the owner can see what was thrown out.
  - A claim about the WORLD OUTSIDE the artifact (what the product already has, what users do, what a competitor ships, that something "caused" a past failure) is NOT a hole the artifact can refute — the reviewer can't know it either. Carry it as an OPEN QUESTION for the owner ("verify: does it already have SSO?"). It may make the recommendation conditional ("if X is true, then …"); it never asserts X. Refute-or-surface at full weight applies to claims about the artifact's own logic, gaps, and consistency.

## SYNTHESIS — `fan-out.md` synthesis, plus the panel rules
CONSUME the frozen Round-1 stacks (lensed + open reads) + ONE cross-examination layer PER SEAT, all keyed by label. The seal was written before any return was opened (SEAL TIMING).
SCORING ORDER: convergence among the LENSED stacks alone keeps `fan-out.md`'s same-model caveat (salient, not proven). Convergence that crosses providers, and every Round-2 result, score by the rules below.
- **CROSS-PROVIDER CONVERGENCE** — the strongest evidence this skill can produce, still NOT proof. Two kinds:
  - at GENERATION: a lensed stack and an open read — or open reads from two providers — raised the same weakness or idea, blind. It outranks any same-model cluster.
  - at CROSS-EXAMINATION: seats from different providers found the same hole, or an idea reached HIGHEST CONFIDENCE (below).
  Every reviewer read one artifact, so a misleading artifact misleads all of them at once; agreement rules out one model's blind spots, not shared-input ones. A hole found by every seat that examined that item — at least two seats, from at least two providers — leads, after the refute check. One seat alone is never "every seat"; score it by the hole rules below.
- **COUNT ONLY THE SEATS THAT LOOKED** — for holes and for survival alike. An open read's item is never examined by its own provider, so "every seat" means the home seat plus the other outside seats.
- **HIGHEST CONFIDENCE** — one rule for every idea, lensed or open read: it survived EVERY seat that examined it, AND at least two seats examined it, AND at least one of those came from a provider other than the one that wrote it. Anything less is a pass, not highest confidence — say which seats passed it. (So a lensed idea passed by the home seat alone is a same-model pass, and an open-read idea passed by the home seat alone is ONE cross-provider pass — neither is convergence.) One seat holing it with a concrete mechanism means it did not survive; that hole is scored by the hole rules below.
- **CAUGHT OMISSION** (an open read raised it; NO lensed stack did) = something the home model never thought of — the generation-side twin of a lone outside hole, and the reason outside providers sit in Round 1. A caught-omission weakness goes through refute-or-surface like any outside finding. A caught-omission idea that reaches HIGHEST CONFIDENCE is top-tier material. Tag both kinds "outside-generated" wherever they appear.
- **LONE OUTSIDE HOLE** (one outside seat found it; the home seat cross-examined that SAME item and did not) = the most valuable finding of the run, because it is most likely a home-model blind spot. If the home seat never cross-examined that item (PARTIAL, excluded, or DEGRADED), it is an outside finding with no control comparison — still full weight via refute-or-surface, but never labeled a home-model blind spot. Refute-or-surface; never let a same-model majority out-vote it.
- **HOME-ONLY HOLE** (the control found it; no outside seat did) = probably real but same-model — ordinary weight.
- **OUTSIDE SEATS DISAGREE** = a fork. Settle it against the artifact, not by counting heads; if you cannot, name it as a fork the owner calls.
- COLLISIONS flagged by any seat -> resolve or name as a fork, exactly as in `fan-out.md`.

## OUTPUT — the `fan-out.md` skeleton, with the panel disclosed
Headline tag names who ACTUALLY ran, in plain words: `FRESH EYES (full panel, tier 4 — ideas from <home model> ×<N> + <outside models>; tested by <home model> + <outside models>)`. Anything missing, failed, or partial — in either round — is named in the tag ("— <provider>'s open read failed: <why>"). Under "Strongest critiques", "Best improvements", and "Ideas that didn't survive scrutiny", say which providers RAISED each item and which providers' seats confirmed or holed it — that agreement is the point of paying for the panel. Caught omissions carry their "outside-generated" tag; unconfirmed outside findings sit in the main lists with their tag, never only in the depth. Add three depth lines:
- `Panel model record: lensed reviewers + home seat on <model>; open reads on <models>; outside seats on <models>`
- `Caught omissions: <what only the outside providers raised — and how each fared under cross-examination> / none`
- `Outside findings dismissed: <finding — the quote that refuted it> / none`

## THE BAR (on top of `fan-out.md`'s)
- PASS requires at least one outside seat that ACTUALLY reviewed (read its return — a refusal or an unlabeled answer is not a review), and every outside finding taken through refute-or-surface. Items marked NOT CROSS-EXAMINED are legal when named — they just never lead. A PARTIAL seat is legal when named; only the items it MISSED are discounted — its findings on the items it DID cover count in full, and can lead.
- Name exactly what ran in EACH round. Zero open reads that actually returned = the ideas came from one model; the tag says so ("ideas from <home model> only — open reads failed: <why>"). It is still a full run if an outside seat reviewed in Round 2. The reverse case — open reads returned, no outside seat reviewed — follows A SEAT FAILS above.
- The worst failure here is claiming tier 4 when only the home model answered — it launders one model's blind spots as cross-provider consensus.
- An outside seat that found no hole anywhere -> `fan-out.md`'s rerun-once rule. Clean again with concrete "survives" entries -> count it, and say so. Hollow entries -> a non-read; do not count it toward convergence.
