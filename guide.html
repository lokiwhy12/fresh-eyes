Skill guide

Fresh Eyes
criticize · improvise · synthesize

Get a real second opinion on any piece of thinking. You get one stronger version back, plus the question you didn’t think to ask.

What it does

You’ve been staring at something you made (a plan, a design, a pitch, some copy, a decision, code) and you’ve gone a little blind to its flaws. Fresh Eyes brings in an outside perspective that doesn’t defend your choices. It attacks the work, invents better options, and hands you back one clear recommendation you can act on.

The core loop. Every run does all three, in order:

1 · Criticize
Find the real weak spots, risks & blind spots.
→
2 · Improvise
Better versions, different approaches, an angle nobody asked for.
→
3 · Synthesize
Merge the best into one ranked recommendation.
Plus: the question you didn’t ask. Every run surfaces the thing one level up: the decision you should settle first, or the wrong assumption baked into your question. Often the most valuable line in the whole report.

One skill, two engines, and it picks for you

Fresh Eyes runs one of two ways, and chooses automatically based on where it’s running. Same folder, both places. You never pick.

In Claude Code

The fan-out engine

Spins up several independent reviewers, each starting blind so they can’t just agree with you. Then the cool part, a “trade homework” round: each reviewer attacks another’s new ideas, so nothing fresh sneaks through unchecked. Then one synthesis.

In the Claude app

The single-mind engine

The chat app can’t spawn separate helpers, so one mind runs the same critique, improve, synthesize discipline in sequence: it commits a guess up front, then hunts it down and argues against itself. Honest about not having true outside eyes.

Why two? The powerful method needs tools that only Claude Code has. Rather than make you keep two skills straight, this one adapts, loading only the engine it’s actually using, so neither side carries the other’s weight.

How to use it

No commands. Just ask in plain words and hand it the thing to look at:

“fresh eyes on this” “pressure-test this plan” “poke holes and make it better” “what am I missing?” “what would someone else say?”
What it’s not for: “Is this correct / done / ready to ship?” That’s a verification pass, a different job. Fresh Eyes makes your thinking better; it doesn’t sign off that it’s right.

Installing it

Skills don’t sync between Claude Code and the app, so install the same folder in each place you want it.

Claude Code

Drop in the folder

Put the fresh-eyes folder in your skills directory:

cp -R fresh-eyes ~/.claude/skills/fresh-eyes

Start a new session and it’s picked up automatically.

Claude app (claude.ai)

Upload the zip

Go to Settings → Features and upload the skill .zip under custom skills. Needs a Pro / Max / Team / Enterprise plan with code execution on.

Fresh Eyes is a set of instructions, nothing more. It writes nothing outside its own folder. Full details in README.md. The two methods live in references/fan-out.md and references/single-mind.md.
